# Радар блогов конкурентов — копия для облачной рутины

Эта папка не публикуется на сайте: она исключена в `.vercelignore`.

Оригинал живёт на Mac Матвея в `~/.claude/skills/malina-blog-radar/`, там же
состояние между запусками. Облачная рутина Claude Code клонирует этот репозиторий
и запускает сканер без состояния:

    python3 tools/blog-radar/scan.py --days 3 --ignore-seen

`--ignore-seen` обязателен: в облаке нет файла состояния, и без флага скрипт
попытается его читать. Список источников и правила их проверки — в
`competitors.md`. Скрипт хранит только заголовок, ссылку, дату и источник
публикации; тела чужих статей он не загружает никогда.

При изменении `scan.py` в навыке — скопировать сюда заново.
